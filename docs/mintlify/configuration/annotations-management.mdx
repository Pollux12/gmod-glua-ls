---
title: Garry's Mod annotations
description: How the Garry's Mod annotations are downloaded and how to change them.
---

GLuaLS knows the Garry's Mod API (every function, hook, class and enum, with types and realms) from annotations generated from the [Garry's Mod wiki](https://wiki.facepunch.com/gmod/). The VS Code extension downloads them on first launch, checks for updates in the background, and shares one copy between all your projects.

To update them now, run **GLuaLS: Update GLuaLS Annotations** from the Command Palette (`Ctrl+Shift+P`).

## VS Code settings

| Setting | Default | Description |
|---|---|---|
| `gluals.gmod.autoLoadAnnotations` | `true` | Download and load the annotations |
| `gluals.gmod.autoCheckAnnotationUpdates` | `true` | Check for updates to the annotations and the debugger in the background |
| `gluals.gmod.annotationUpdateCheckIntervalMinutes` | `60` | Minutes between update checks |
| `gluals.gmod.annotationsChannel` | `"auto"` | `"stable"`, `"prerelease"`, or `"auto"` to match your extension version |
| `gluals.gmod.annotationsRepository` | `"Pollux12/annotations-gmod-glua-ls"` | GitHub repository to download from |
| `gluals.gmod.annotationsBranch` | `"gluals-annotations"` | Download a specific branch instead of using the channel |
| `gluals.gmod.annotationsCommit` | `""` | Download one exact commit. This turns off update checks |

Keep the defaults unless you are testing changes to the annotations.

## Use your own copy

To use a local folder of annotations for one project, set `gmod.annotationsPath` in `.gluarc.json`. The path can be absolute or relative to the project folder.

```json .gluarc.json
{
  "gmod": {
    "annotationsPath": "../my-annotations"
  }
}
```

To load no Garry's Mod annotations for a project, set `gmod.autoLoadAnnotations` to `false`.
