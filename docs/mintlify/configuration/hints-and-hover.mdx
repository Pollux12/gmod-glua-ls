These are display settings, so many people set them in VS Code settings (`gluals.*`) instead of `.gluarc.json`. Set `gluals.hint.enable` to `false` to turn all inlay hints off at once.

## Inlay hints

Inlay hints are the small grey labels shown inside your code.

| Option | Default | Shows |
|---|---|---|
| `hint.paramHint` | `true` | Parameter names next to call arguments |
| `hint.localHint` | `true` | The type of each local variable |
| `hint.enumParamHint` | `true` | The enum name for a number passed where an enum is expected, such as `MASK_SOLID` |
| `hint.indexHint` | `true` | Names for numbered table entries |
| `hint.overrideHint` | `true` | A marker on methods that override a base class method |
| `hint.metaCallHint` | `true` | A marker on calls to tables that have a `__call` function in their metatable |
| `hint.closingEndHint` | `true` | The function name after the `end` of a long function |
| `hint.closingEndHintControlFlow` | `false` | The same for `if`, `for`, `while` and `do` blocks |
| `hint.closingEndHintMinLines` | `15` | How many lines a block needs before it gets an `end` hint |

## Editor features

| Option | Default | Description |
|---|---|---|
| `hover.enable` | `true` | Documentation when you hover code |
| `codeLens.enable` | `true` | Reference counts and links shown above functions |
| `semanticTokens.enable` | `true` | Coloring based on what each name is, such as global, local or field |
| `semanticTokens.renderDocumentationMarkup` | `true` | Render Markdown in documentation |
| `inlineValues.enable` | `true` | Variable values shown in the editor while the debugger is paused |
| `documentColor.enable` | `true` | Color previews and a color picker for `Color(...)` calls |
| `references.enable` | `true` | **Find All References** |
| `references.fuzzySearch` | `true` | Fall back to a looser search when nothing is found |
| `references.shortStringSearch` | `false` | Also search inside strings |
