GLuaLS includes a formatter. Format a file with **Format Document** (`Shift+Alt+F`). To format on every save, turn on `editor.formatOnSave` in VS Code.

<Frame>
  <img src="/images/showcase/settings-formatter.gif" alt="Choosing the CFC preset in the settings panel, saving, and formatting a file" />
</Frame>

These settings live under `format` in `.gluarc.json`.

## Options

| Option | Default | Description |
|---|---|---|
| `format.preset` | `"default"` | Starting style: `"default"`, `"cfc"` (the [CFC style guide](https://github.com/CFC-Servers/cfc_glua_style_guidelines)) or `"custom"` (no preset, only your overrides) |
| `format.styleOverrides` | none | Individual style options applied on top of the preset |
| `format.configPrecedence` | `"preferEditorconfig"` | Which wins when `.editorconfig` and `styleOverrides` disagree: `"preferEditorconfig"` or `"preferGluarc"` |
| `format.useDiff` | `false` | Apply only the changed parts of the file instead of replacing it all |
| `format.externalTool` | none | Format whole files with another program |
| `format.externalToolRangeFormat` | none | Format selections with another program |

```json .gluarc.json
{
  "format": {
    "preset": "cfc",
    "styleOverrides": {
      "indent_style": "tab",
      "max_line_length": 110
    }
  }
}
```

## Style options

The settings panel lists every style option with a description. These are the most common:

| Option | Values |
|---|---|
| `indent_style` | `"space"` or `"tab"` |
| `indent_size` | Spaces per indent level |
| `tab_width` | Width of a tab |
| `quote_style` | `"none"`, `"single"` or `"double"` |
| `max_line_length` | Column limit, or `"unset"` |
| `end_of_line` | `"crlf"`, `"lf"`, `"cr"`, `"auto"` or `"unset"` |
| `insert_final_newline` | `true` or `false` |
| `trailing_table_separator` | `"keep"`, `"never"`, `"always"` or `"smart"` |
| `call_arg_parentheses` | `"keep"`, `"remove"`, `"remove_table_only"`, `"remove_string_only"` or `"always"` |
| `space_around_table_field_list` | Spaces inside table braces: `{ x = 1 }` |
| `space_inside_function_call_parentheses` | Spaces inside call parentheses: `f( x )` |
| `space_inside_function_param_list_parentheses` | Spaces inside parameter lists: `function f( x )` |
| `space_around_math_operator` | Spaces around `+`, `-`, `*` and `/` |
| `space_after_comma` | Space after `,` |
| `align_continuous_assign_statement` | Line up `=` across neighboring assignments |
| `line_space_after_function_statement` | Blank lines after functions: `"keep"`, `"fixed(n)"`, `"min(n)"` or `"max(n)"` |

## External formatter

To use another formatter such as StyLua, give its command and arguments. GLuaLS sends the file on standard input and reads the result from standard output. `${file}` is replaced with the file path.

```json .gluarc.json
{
  "format": {
    "externalTool": {
      "program": "stylua",
      "args": ["--stdin-filepath", "${file}", "-"],
      "timeout": 5000
    }
  }
}
```
