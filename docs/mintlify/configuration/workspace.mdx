---
title: Workspace settings
description: Choose which files GLuaLS reads, skips or uses as libraries.
---

These settings live under `workspace` in `.gluarc.json`. For the common cases, see [Open your project](/getting-started/workspace-setup).

## Options

| Option | Default | Description |
|---|---|---|
| `workspace.library` | `[]` | Folders outside your project to read for types and functions, without showing their warnings |
| `workspace.ignoreDir` | `[]` | Folders to skip |
| `workspace.ignoreGlobs` | `[]` | Glob patterns of files to skip |
| `workspace.useDefaultIgnores` | `true` | Skip the built-in list of folders below |
| `workspace.ignoreDirDefaults` | built-in list | Change the built-in list |
| `workspace.enableIsolation` | `false` | In a multi-root workspace, keep each folder to its own code and libraries, so it cannot use another folder's functions and classes. It stays on only when every folder turns it on |
| `workspace.workspaceRoots` | `[]` | Extra folders to treat as roots for `require` paths |
| `workspace.packageDirs` | `[]` | Load only these folders from their parent library |
| `workspace.moduleMap` | `[]` | Rewrite `require` paths with regex rules |
| `workspace.encoding` | `"utf-8"` | Text encoding of your Lua files |
| `workspace.enableReindex` | `false` | After you save and stop typing, recheck every file and drop files deleted outside VS Code |
| `workspace.reindexDuration` | `5000` | How long to wait after typing stops before that recheck, in milliseconds |

## Libraries

Each library is a path, or an object with its own skip rules. Relative paths start from your project folder.

```json .gluarc.json
{
  "workspace": {
    "library": [
      "../shared-library",
      {
        "path": "C:/srcds/garrysmod/addons/some-framework",
        "ignoreDir": ["tests"],
        "ignoreGlobs": ["**/*_old.lua"]
      }
    ]
  }
}
```

## Built-in skip list

GLuaLS skips these by default:

| id | Pattern |
|---|---|
| `git` | `**/.git/**` |
| `github` | `**/.github/**` |
| `claude` | `**/.claude/**` |
| `agents` | `**/.agents/**` |
| `gemini` | `**/.gemini/**` |
| `vscode` | `**/.vscode/**` |
| `idea` | `**/.idea/**` |
| `svn` | `**/.svn/**` |
| `hg` | `**/.hg/**` |
| `node-modules` | `**/node_modules/**` |
| `wire-expression2` | `**/gmod_wire_expression2/**` |
| `wire-expression-files` | `**/wire_expression*.lua` |
| `tests` | `**/tests/**` |
| `test` | `**/test/**` |

To change one entry, list it by `id` in `ignoreDirDefaults`. Entries you leave out keep their default.

```json .gluarc.json
{
  "workspace": {
    "ignoreDirDefaults": [
      { "id": "tests", "disabled": true },
      { "id": "legacy", "glob": "**/legacy/**" }
    ]
  }
}
```

Use `disabled: true` to stop skipping a built-in entry, a new `id` to add an entry, or an existing `id` with a new `glob` to change its pattern. To turn off the whole list, set `useDefaultIgnores` to `false`.

## Module map

If your project loads modules from non-standard paths, rewrite them with regex rules:

```json .gluarc.json
{
  "workspace": {
    "moduleMap": [
      { "pattern": "^libs/(.*)", "replace": "lua/libs/$1" }
    ]
  }
}
```
