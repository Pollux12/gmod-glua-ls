---
title: Completion settings
description: Change how suggestions and snippets work.
---

These settings live under `completion` in `.gluarc.json`.

| Option | Default | Description |
|---|---|---|
| `completion.enable` | `true` | Show suggestions |
| `completion.callSnippet` | `true` | Insert functions with placeholders for their arguments |
| `completion.stagedCallSnippets` | `true` | Guide you through calls such as `hook.Add` and `net.Receive` one argument at a time, then fill in the callback parameters |
| `completion.baseFunctionIncludesName` | `true` | Include the function name when completing a function definition |
| `completion.postfix` | `"@"` | Character that opens postfix suggestions after a value, such as `tbl@` for a `pairs` loop |
| `completion.autoRequire` | `true` | Add a `require` line when you pick a symbol from another module |
| `completion.autoRequireFunction` | `"require"` | Function used for that line |
| `completion.autoRequireNamingConvention` | `"keep"` | Name of the local it creates: `"keep"`, `"snake-case"`, `"pascal-case"`, `"camel-case"` or `"keep-class"` |
| `completion.autoRequireSeparator` | `"."` | Separator used in the module path |

```json .gluarc.json
{
  "completion": {
    "callSnippet": false,
    "postfix": "."
  }
}
```
