## Overview

GLuaLS handles some Lua built-ins, such as `pairs`, specially. For example, it follows the keys a `pairs` loop visits.

Annotation files redeclare those built-ins to add Garry's Mod details. `builtin_alias` names the built-in a declaration stands for, so the special handling carries over.

---

## Syntax

```lua
---@[builtin_alias("name")]
```

Put it after the `@return` line.

---

## Example

```lua
---@generic K, V
---@param t table<K, V>
---@return fun(tbl: table<K, V>, index: K?): K, V
---@[builtin_alias("pairs")]
function _G.pairs(t) end
```

If your own code declares a global `pairs`, that declaration wins and the special handling stops.
