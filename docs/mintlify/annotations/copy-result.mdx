## Overview

`copy_result` marks a function such as `table.Copy` that returns a new table starting with the contents of its first argument.

The copy keeps the original's fields and methods. Fields you add to the copy stay on the copy and never show on the original.

---

## Syntax

```lua
---@return T
---@[copy_result]
```

Put it after the `@return` line.

---

## Example

```lua
---@generic T
---@param originalTable T
---@return T
---@[copy_result]
function table.Copy(originalTable) end
```

```lua
local defaults = { Speed = 10 }
local settings = table.Copy(defaults)
settings.Extra = true

print(settings.Speed) -- number
print(defaults.Extra) -- undefined field
```
