## Overview

`@class` defines a named type that other annotations can use. Classes support inheritance, generic type parameters, access control, and field definitions.

---

## Syntax

```lua
---@class ClassName
---@class ClassName : ParentClass
---@class ClassName : Parent1, Parent2
---@class (exact) ClassName
---@class (partial) ClassName
---@class ClassName<T>
```

---

## Basic class <a id="basic-class" />

```lua
---@class Animal
---@field name string Animal name
---@field species string Species
local Animal = {}

function Animal:Speak()
    print(self.name .. " makes a sound")
end
```

---

## Inheritance <a id="inheritance" />

Use `: ParentClass` to extend another class. The child class gets the parent's fields and methods.

```lua
---@class Dog : Animal
---@field breed string Dog breed
local Dog = setmetatable({}, { __index = Animal })

function Dog:Fetch(item)
    -- inherits Animal fields: self.name, self.species ✅
end
```

### Multiple inheritance <a id="multiple-inheritance" />

```lua
---@class Flyable
---@field maxAltitude number

---@class Swimmable
---@field maxDepth number

---@class Duck : Animal, Flyable, Swimmable
---@field featherColor string
```

## Metatable classes <a id="metatable-classes" />

GLuaLS reads common metatable code as classes, so you don't need `@class` for it:

```lua
local COLOR = {}
COLOR.__index = COLOR
function COLOR:Brighten() return self end
RegisterMetaTable("MyColor", COLOR)

local c = setmetatable({}, COLOR)       -- MyColor
local meta = FindMetaTable("MyColor")  -- MyColor
```

It also follows:

- `newproxy(true)` and `getmetatable(proxy)`. A proxy made with `newproxy(other)` shares `other`'s metatable.
- Factories. A function that registers the table it returns makes a class at each call, so `local BONE = CreateMetaTable("Bone")` gives `BONE` the class that call registers. Whatever the factory puts on that table belongs to every class it makes.
- Writes a factory makes under its arguments, such as `Registry[name] = meta` or `Make[name] = function(...) return setmetatable({}, meta) end`. Each call names them: `Registry.Bone` is the class, and `Make.Bone()` returns it.
- An `__index` function. A key the class doesn't define reads what `__index` returns. If `__index` returns `Storage[self][key]` or `rawget(Storage, key)`, the fields of that table become the object's fields.
- Custom inheritance. If `__index` walks parents with `meta = rawget(meta, "Parent")` or `meta = meta.Parent`, each class inherits from what its factory call stores in `Parent`.
- Subclasses. `local Dog = setmetatable({}, Animal)` with `Dog.__index = Dog` inherits `Animal`'s methods, and the methods you define on `Dog` stay off `Animal`.
- Constructors that work on their receiver, such as `function Class:new(o) setmetatable(o, self) self.__index = self return o end`. Each call makes an instance of the table it's called on, so `Special = Account:new()` followed by `function Special:limit() end` is a subclass of `Account`.
- `__call`. Calling a table runs its `__call` with the table passed first, so `Point(1, 2)` returns what `__call` returns.
- Operators. `a + b`, `-a`, `a .. b` and the other operators return what the metamethod (`__add`, `__unm`, `__concat`, ...) returns.
- `__metatable`. `getmetatable(t)` returns the metatable's `__metatable` field when it has one.

Annotate only when the code builds names or parents in ways GLuaLS can't follow, for example `string.upper(name)` as a key.

## Exact classes <a id="exact-classes" />

Mark a class as `(exact)` to prevent dynamic field additions. GLuaLS can report a diagnostic when code assigns a field outside the class definition:

<Info>
In GLuaLS, this annotation has no effect. GLuaLS treats all classes as partial by default and turns related diagnostics off. GLuaLS keeps it for EmmyLua compatibility.
</Info>

```lua
---@class (exact) Point
---@field x number
---@field y number

local p = Point.new(1, 2)
p.z = 3 -- ❌ Error: cannot add field 'z' to exact type Point
```

---

## Partial classes <a id="partial-classes" />

`(partial)` extends an existing class without relisting all fields:

<Info>
In GLuaLS, this annotation has no effect. GLuaLS treats all classes as partial by default and turns related diagnostics off. GLuaLS keeps it for EmmyLua compatibility.
</Info>


```lua
-- In one file:
---@class Animal
---@field name string

-- In another file:
---@class (partial) Animal
---@field weight number  -- adds weight to Animal without losing name
```

## Generic classes <a id="generic-classes" />

Add type parameters with angle brackets. You can use type parameters in field types:

```lua
---@class Container<T>
---@field items T[]
---@field capacity number

---@type Container<string>
local stringContainer = { items = {}, capacity = 10 }
stringContainer.items[1] = "hello" -- ✅ typed as string
```

## Field access control <a id="field-access-control" />

Use access modifiers in `@field`:

<Info>
Access modifiers are optional. They affect type checking only, not runtime behavior. GLuaLS checks them and can report diagnostics when code uses private or protected fields from the wrong place.
</Info>

```lua
---@class MyClass
---@field public name string Accessible everywhere
---@field private m_id number Only accessible in class methods
---@field protected m_parent MyClass Accessible in subclasses
```

See [@field](/annotations/field) for details.

## Attaching a class to a local variable <a id="attaching-a-class-to-a-local-variable" />

When you place `---@class` above a `local` statement, GLuaLS types that variable as an instance of the class:

```lua
---@class Player
local Player = {}
-- Player is now typed as "instance of Player class"
```

To type a *constructor* table instead, use `@type`:

```lua
local Player = {}
---@type Player
local ply = Player.new()
```
