## Overview

The VS Code extension runs a local [Model Context Protocol](https://modelcontextprotocol.io/) server for AI-assisted GLua development. It works with VS Code chat and other MCP-compatible agents.

The server combines three parts of your development environment:

- The active Garry's Mod debugger session for Lua execution
- Captured server and client console output
- Runtime Lua errors and GLuaLS language diagnostics

<Warning>
`execute_lua` can change game state. Only connect agents you trust, and only install `gm_rdb` on development servers.
</Warning>

## Available tools

The server intentionally exposes only three tools:

| Tool | Description |
|---|---|
| `execute_lua` | Execute up to 256 KiB of queued Lua in the `server`, `client`, or `shared` realm |
| `read_console` | Read recent timestamped console lines, optionally after a previous cursor |
| `read_issues` | Read timestamped runtime errors and current GLuaLS errors/warnings |

`execute_lua` returns dispatch status and an observation cursor. Pass that cursor to `read_console` after execution, and call `read_issues` to inspect runtime failures. This avoids incorrectly attributing delayed client output to a later execution. Use `print(...)` in the chunk to return values through the console.

<Warning>
The debugger bridge broadcasts `client` and `shared` execution to every player connected to the development server. The tool rejects those realms unless the request explicitly sets `confirmClientBroadcast` to `true`. Use the `server` realm unless you intend to run the code on every connected client.
</Warning>

The runtime tools require the [debugger](/debugger/setup). `read_issues` can return language diagnostics without a running game.

## Connect from VS Code

VS Code discovers the GLuaLS MCP server automatically. Open the chat tool picker and enable **GLuaLS Garry's Mod Runtime**. You do not need to configure a separate Copilot integration.

## Connect another AI agent

<Steps>
  <Step title="Start GLuaLS in VS Code">
    Open your GLua workspace in VS Code. The extension hosts the MCP server because it owns the debugger connection and language diagnostics.
  </Step>
  <Step title="Copy the connection configuration">
    Run **GLuaLS: MCP: Copy Server Configuration** from the Command Palette. The command copies the current Streamable HTTP URL and bearer token.
  </Step>
  <Step title="Add it to your agent">
    Paste the copied server entry into your agent's MCP configuration. The exact outer property can vary between clients; the copied object uses VS Code's `servers` format.
  </Step>
  <Step title="Connect the debugger">
    Start a Garry's Mod debug session before asking the agent to execute Lua. Console and runtime error capture starts with the debug session.
  </Step>
</Steps>

The copied entry has this shape:

```json
{
  "servers": {
    "gluals-gmod": {
      "type": "http",
      "url": "http://127.0.0.1:21113/mcp",
      "headers": {
        "Authorization": "Bearer <generated-token>"
      }
    }
  }
}
```

## Example workflow

```text
You: Check the current map and report any Lua failures.

Agent: [calls execute_lua with print(game.GetMap())]
Agent: [calls read_issues]
Agent: The server is running gm_construct. No runtime Lua errors were captured,
       but GLuaLS reports one warning in lua/autorun/example.lua:14.
```

For repeated console reads, pass the `cursor` from the previous `read_console` response. This returns only newer lines and avoids confusing old output with the current test.

## Security

The MCP server:

- Binds only to `127.0.0.1`
- Requires a bearer token for every request
- Stores its generated token in VS Code secret storage
- Validates host and origin headers to prevent DNS rebinding
- Rate-limits requests and bounds request/output sizes
- Marks game output as untrusted runtime data in tool responses

Set `gluals.gmod.mcp.authToken` only if you need a fixed token. Leaving it empty is safer for most users.

## Settings

| Setting | Default | Description |
|---|---|---|
| `gluals.gmod.mcp.enabled` | `true` | Start the local MCP server |
| `gluals.gmod.mcp.port` | `21113` | Streamable HTTP port. `0` chooses an available port |
| `gluals.gmod.mcp.authToken` | `""` | Bearer token override. Empty securely generates and stores a token |
| `gluals.gmod.mcp.rateLimitPerMinute` | `120` | Maximum MCP requests per minute for each local client |

If you set the port to `0`, copy a new external-agent configuration after each extension restart because the ephemeral URL can change.
