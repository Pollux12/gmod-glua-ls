---
title: Command-line checks
description: Run GLuaLS diagnostics from a terminal or in CI.
---

`glua_check` runs the same checks as the editor, without opening an editor. Use it in CI to catch problems before they are merged.

## Install

Download `glua_check` for Windows or Linux from the [GitHub releases](https://github.com/Pollux12/gmod-glua-ls/releases), or install it with Cargo:

```bash
cargo install glua_check
```

`glua_check` needs the Garry's Mod annotations. Download the [`gluals-annotations` branch](https://github.com/Pollux12/annotations-gmod-glua-ls/tree/gluals-annotations) and pass its folder with `--gmod-annotations`.

## Check a project

```bash
glua_check . --gmod-annotations ./annotations
```

It reads `.gluarc.json` from the project and prints every warning and error. It exits with code `1` when it finds an error. Add `--warnings-as-errors` to fail on warnings too.

Pass several folders to check them together, like a multi-root workspace.

## Options

| Option | Description |
|---|---|
| `--gmod-annotations <PATH>` | Folder with the Garry's Mod annotations |
| `--warnings-as-errors` | Exit with code `1` on warnings as well |
| `-f, --output-format <FORMAT>` | `text` (default), `json` or `sarif` |
| `--output <FILE>` | Write `json` or `sarif` output to a file |
| `-c, --config <PATHS>` | Use these config files instead of `.gluarc.json`, separated by commas |
| `-i, --ignore <PATTERNS>` | Skip files matching these glob patterns, separated by commas |
| `--verbose` | Print more detail while loading |

SARIF output works with GitHub code scanning, which shows the results on pull requests.
